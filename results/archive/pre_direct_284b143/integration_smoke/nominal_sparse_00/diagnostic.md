# nominal_sparse_00 开发试跑诊断

本回合属于开发集成试跑。正式 Table III 统计使用独立结果目录。

## 首次失效

按预先确定的机体包络判据，首次触发时间为 **1.728571 s**。位置为 **[-8.439774, -3.105456, 1.134241] m**。最近障碍是圆柱 **id = 37**。

中心到实体障碍的净空为 **0.324688 m**。减去 **0.003164 m** 的几何与线段采样误差界后，下界为 **0.321524 m**，低于机体半径 **0.322 m**。该时间是保守判据的首次触发时间，精确实体接触时间未单独求解。

证据见 `summary.json`、`trajectory.csv` 和固定的 `experiments/scenes/sparse.json`。

## 接口一致性

用记录的状态和 CTBR 代入原版 RK4 公式，共核对 **1205 个状态转移**。最大绝对残差为 **1.4211 × 10⁻¹⁴**。控制时间戳与其起始状态时间戳的最大偏差为 **0 s**。状态步长与 **0.05 s** 的最大偏差为 **4.27 × 10⁻¹⁵ s**。

状态顺序为 `[p, v, qw, qx, qy, qz]`。控制顺序为 `[ωx, ωy, ωz, 归一推力]`。初始四元数 `[0, 0, 0, 1]` 对应 yaw π。原版与移植版均先移动 U，再执行第 0 行，即原优化结果的第二个控制。

上述记录未显示状态排列、CTBR 次序或 nominal 时间步错误。此次检查仅计算已有记录的转移残差，没有重跑仿真或优化器。原版与移植版动力学头文件的 SHA256 相同。
