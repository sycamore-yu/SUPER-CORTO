# 结果目录

`table3/` 保存冻结源码后执行的正式 60 回合。
每个执行条件分别包含 Sparse、Medium、Dense 各 10 回合。
正式统计只使用该目录的预定回合。

其他目录保存开发与验证证据：

- `numerical_regression/`：固定输入的上游与移植数值比较。
- `validation/`：统一编译、地图契约及动力学测试日志。
- `simulator_smoke*`：两种动力学模式的接口和 LiDAR 检查，包括早期失败记录。
- `integration_smoke/`：采用旧终止规则的开发试跑及诊断。
- `integration_terminal_smoke/`：首次终止规则与 RViz 检查，保留发现的节点退出异常。
- `integration_shutdown_smoke/`：退出流程修复后的集成检查。
- `integration_final/`：正式实验后补充休眠异常处理，再次验证两种模式正常退出。

开发试跑未计入正式成功率或规划时间。
同一规划种子在不同调度时序下可能产生不同异步交接结果。
固定种子不表示实际时间驱动的闭环运行逐位一致。

正式回合全部使用 `ef8e8e472dbbac40f4b91581582d848a83697234`。
其中 20 次节点关闭异常均发生在采集和评分完成后。
原日志保留，最终代码的关闭修复另有验证记录。
