# 直接动力学清理与验收

## 已确认设计

CORTO 在同一控制循环内执行原版 CTBR → 10 状态 RK4，步长 0.05 s。
SUPER 的 PerfectDrone 读取完整 Odometry，转发状态、TF 并渲染 LiDAR。
只保留这一执行路径，删除 EGO 源码、控制器、电机分配、独立物理线程及模式开关。
NMPC、规划、原版输入移位和异步计划交接算法保持原样。

碰撞和越界记录为事件；到达、原版任务结束、超时或数值异常结束采集。
删除 0.322 m 包络、边界内缩、5 mm 扫掠采样和额外误差扣减。
按原始 20 Hz 状态样本统计中心点净空、碰撞和地图越界。
分别报告到达率与无碰撞且未越界的成功率。
固定地图和规划种子不变，三场景各运行 10 回合。

## 验收要点

发布的位姿、速度、角速度和时间戳与 CORTO 状态一致。
仿真时钟只由 CORTO 模型步推进；求解墙钟时间单独记录。
固定输入与上游数值一致，新增记录器不干预控制。
旧数据保留在 `results/archive/`，旧实现只在 Git 历史中保留。
