# 执行链检查

当前模型状态由 CORTO 的原版 RK4 唯一推进。
PerfectDrone 消费完整 Odometry，转发位姿、速度和时间戳并渲染。
已删除原有的独立电机执行链、物理线程和模式切换。

记录器的碰撞和越界处理仅追加事件。
实际 ROS 测试覆盖“碰撞 → 越界 → 重规划失败 → 到达”的完整序列。
到达被保留，安全成功为 false。

保留原版算法和实际需要的检查：地图边界语义、非有限状态、运行超时、
原始数据防覆盖，以及关闭时 join 规划线程。
关闭异常处理只允许已停止 ROS context 上的对应错误。

验证日志见 `results/validation_direct/`。
